## Running the project

```bash
# Install dependencies
pip install -r requirements.txt

# Run the Streamlit dashboard (main app)
streamlit run startupapp.py

# Regenerate/update the CSV dataset and run the data pipeline
python developmentday2.py
```

TensorFlow is optional. Without it, LSTM predictions are skipped and the app falls back gracefully. Install with `pip install tensorflow` to enable LSTM training.

## Architecture

The project is a sports performance AI platform for football athletes. It has two layers:

**Data engine** (`developmentday2.py`):
- Generates or updates `biometria_performance_startup.csv` (100-day synthetic athlete dataset)
- Contains all core ML logic: ACWR, Recovery Score, Metabolic Power, LSTM training
- Run this script first when adding new metrics or reseeding data; it writes results back to CSV

**Streamlit dashboard** (`startupapp.py`):
- Reads from `biometria_performance_startup.csv` via `@st.cache_data`
- Recomputes derived columns (Eficiência, Sono Eficiência, ACWR, BME metrics) on load to stay in sync even when the CSV was generated by an older version of the engine
- Organized into 5 navigation levels via sidebar radio: Dashboard Geral → Performance Física → Recuperação Interna → IA Preditiva → Visão Completa

**Shared data contract** (CSV columns both files must agree on):
`HRV_ms`, `Sono_Profundo_h`, `Horas_Sono`, `Distancia_km`, `Minutos_High_Intensity`, `Velocidade_Max_kmh`, `Assimetria_Percent`, `Carga_Mecanica_G`, `Carga_Mecanica_G_Raw`, `ACWR`, `Readiness`, `Eficiencia`, `Diagnostico_IA`, `Diagnostico_Sono`, `Status_Adaptacao`, `Resistencia`

## Key domain concepts

- **ACWR** (Acute:Chronic Workload Ratio): 7-day rolling mean / 28-day rolling mean of `Carga_Mecanica_G`. Safe zone 0.8–1.3; >1.5 triggers injury risk alert.
- **Carga_Mecanica_G**: Raw impact load (distance × random multiplier) smoothed with a Butterworth lowpass filter (order 3, cutoff 0.2 Hz); fallback is a 3-sample rolling mean when SciPy is unavailable.
- **Recovery Score** (`calcular_recovery_scores`): 3-pillar composite — SNA (HRV z-score + SpO2) × 0.5 + Sleep × 0.3 + Strain (ACWR) × 0.2; capped at 50 when ACWR > 1.5.
- **Metabolic Power**: Estimated from simulated speed/acceleration profiles using the Minetti EC polynomial. Entry point is `estimate_metabolic_metrics_for_dataset()`.
- **LSTM** (`train_lstm_predict_readiness`): Predicts next-day Readiness using a 7-timestep window; model saved to `readiness_lstm_model.h5` and loaded by the dashboard if present.

## Earlier exploration scripts

`development1.py` and `developmentday1complete.py` are standalone matplotlib dashboards used during prototyping (interactive athlete selector via `input()`). They are not part of the Streamlit app flow but contain useful biomedical signal processing patterns (Butterworth filter, K-means clustering for athlete state classification).
